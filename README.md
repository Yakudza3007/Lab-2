## Задание 3. Ломаная

### Задача 2

- **Текст задачи:** Создать класс `Polygonal`, представляющий ломаную линию в виде массива точек. Необходимо создать две ломаные, у которых совпадают начальная и конечная точки, а затем изменить координаты общей начальной точки так, чтобы изменения отразились в обеих ломаных.
- **Алгоритм решения:** Созданы классы `Point` и `Polygonal`. Класс `Point` хранит координаты X и Y и возвращает их строковое представление в формате `{X;Y}`. Класс `Polygonal` хранит массив точек и выводит ломаную в виде списка этих точек. Для обеих ломаных используется один и тот же объект начальной точки.
- **Тестирование:** Созданы две ломаные с общей начальной точкой `{1;5}` и конечной точкой `{5;3}`. После изменения координат начальной точки проверено, что изменения отображаются в обеих ломаных.

## Задание 5. Длина ломаной

### Задача 7

- **Текст задачи:** Дополнить класс `Polygonal` возможностью добавлять к существующим точкам новые точки или массивы точек, а также вычислять общую длину ломаной.
- **Алгоритм решения:** Реализованы методы `Add()` для добавления одной точки и массива точек. При добавлении создаётся новый массив, содержащий старые и новые точки. Метод `Length()` вычисляет длину ломаной как сумму расстояний между соседними точками по формуле расстояния между двумя точками на плоскости.
- **Тестирование:** Создана ломаная через точки `{1;5}`, `{2;8}`, `{5;3}`. Вычислена её длина. Затем добавлены точки `{5;15}` и `{8;10}`, после чего длина вычислена повторно. Проверено увеличение длины после добавления точек.
